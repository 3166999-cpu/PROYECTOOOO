INVESTIGACIÓN 02

jQuery

Una biblioteca que facilita el trabajo con JavaScript.

CONCEPTO

¿Qué es jQuery?

Definición

jQuery es una biblioteca de JavaScript creada para simplificar tareas frecuentes relacionadas con la manipulación de páginas web.

Su sintaxis permite seleccionar elementos HTML, modificarlos, crear eventos y realizar efectos con menos código.

¿Por qué nació?

jQuery surgió para facilitar el desarrollo web y reducir algunas diferencias de funcionamiento entre los navegadores que existían en los primeros años del desarrollo web moderno.

$

jQuery

WRITE LESS • DO MORE

SINTAXIS

El símbolo $

$(selector)

El signo $ es una de las características más conocidas de la sintaxis de jQuery. 


$("#mensaje").hide();

$(".producto").show();

$("button").click(function(){
    alert("Hola");
});

VENTAJAS Y DESVENTAJAS

jQuery frente a JavaScript moderno

Ventajas

✓ Sintaxis sencilla.

✓ Facilita la manipulación del DOM.

✓ Tiene numerosos efectos.

✓ Fue muy útil para compatibilidad entre navegadores.

Desventajas

✗ Agrega una dependencia externa.

✗ Algunas tareas modernas ya son sencillas con JavaScript.

✗ Puede ser innecesario en proyectos pequeños.

JavaScript moderno

Actualmente JavaScript cuenta con APIs y métodos que permiten realizar muchas tareas sin necesidad de utilizar jQuery.
