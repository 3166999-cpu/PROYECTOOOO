Web Hosting y Dominios

¿Cómo publicar una página web en Internet?

WEB HOSTING

¿Qué es un Hosting?

Definición

El Web Hosting es un servicio que permite almacenar los archivos de una página web en un servidor conectado a Internet.

Cuando una persona visita una página, el navegador solicita los archivos al servidor y posteriormente los muestra en pantalla.

WEB

HOSTING

ARCHIVOS • SERVIDOR • INTERNET

TIPOS

Tipos de Hosting

Compartido

Varios sitios web utilizan recursos del mismo servidor.

VPS

Un servidor físico se divide en servidores virtuales independientes.

Nube

Utiliza recursos distribuidos en diferentes servidores.

Servidor dedicado

Un servidor completo se dedica a un proyecto o cliente.

DESPLIEGUE

¿Cómo funciona Vercel?

Vercel

Vercel es una plataforma utilizada para desplegar proyectos web. Puede conectarse con repositorios de GitHub para realizar despliegues.

Proceso básico

1. Crear el proyecto web.

2. Subir el proyecto a GitHub.

3. Conectar el repositorio con Vercel.

4. Vercel realiza el despliegue.

5. Se obtiene una URL pública.

DOMINIOS

¿Qué es un dominio?

Dominio

Es el nombre que identifica a un sitio web en Internet. 

nicolefashion.com

TLD

Es la extensión que aparece al final del dominio. 

.com
.net
.org

Subdominio

Es una división dentro de un dominio. 

tienda.nicolefashion.com
