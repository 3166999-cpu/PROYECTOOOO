¿Qué es JavaScript?

Definición

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite que una página responda a las acciones realizadas por los usuarios.

Con JavaScript podemos modificar elementos HTML, cambiar estilos, mostrar mensajes, validar formularios, crear animaciones y desarrollar diferentes funciones interactivas.

¿Para qué se utiliza?

Se utiliza para agregar comportamiento dinámico a los sitios web. Por ejemplo, cuando un usuario presiona un botón y aparece un mensaje, JavaScript puede ser el encargado de realizar esa acción.

CONCEPTOS FUNDAMENTALES

HTML + CSS + JavaScript

HTML

Estructura

Define los elementos y contenidos de una página web.

CSS

Diseño

Se encarga de los colores, tamaños, posiciones y apariencia.

JavaScript

Comportamiento

Permite crear funciones e interacciones dentro de la página.

Resultado

Web interactiva

Los tres trabajan juntos para crear una experiencia web completa.

CONCEPTOS BÁSICOS

Variables, funciones y eventos

Variables

Una variable permite guardar información que puede utilizarse posteriormente. 

let nombre = "Nicole";
let precio = 29.99;

Funciones

Una función es un bloque de código que realiza una tarea determinada. 

function saludar() {
    alert("Bienvenida");
}

Eventos

Los eventos permiten responder a acciones como hacer clic o mover el mouse. 

boton.addEventListener(
    "click",
    mostrarMensaje

COMPARACIÓN

JavaScript Vanilla

¿Qué significa Vanilla JavaScript?

Vanilla JavaScript significa utilizar JavaScript directamente, sin depender de una biblioteca o framework externo.

Es una forma importante de aprender los fundamentos del lenguaje porque permite trabajar directamente con HTML, CSS y el DOM.
